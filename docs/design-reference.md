## Borrowed Design Language
- Typography-led, high-contrast monochrome aesthetic (`#FDFDFD`, `#0A0909`, `#707070`, `#E8E8E8`, `#242424`).
- Oversized display typography with outlined first name + solid filled last name.
- Centered, high-contrast monochrome portrait cutout overlapping typography.
- Editorial hairlines, crosshairs (`+`), and pill controls.
- Independent atmospheric backdrop aura.
- Capability accordion replacing generic card boxes.
- Distinct high-contrast dark experience section.
- Clean closing contact CTA.
